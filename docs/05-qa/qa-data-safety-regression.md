## 隔离模拟测试结果

以下为测试代码的断言结果，不是浏览器验收：

- 损坏 JSON、空字符串、缺失 schema 和 schema 2：进入恢复状态，模拟渲染包含恢复提示，保存被拒绝，原始快照不变且无写入。模拟读取异常也阻止保存。
- schema 1 旧式顶层失败经验字段可映射，菜谱及数据库额外字段保留在模拟内存中。
- 无效 JSON、缺失或不支持 schema、异常菜谱结构的导入不替换原快照及内存；取消确认和模拟写入配额错误不替换原快照；配额错误保留原内存并提示保存失败；有效空库导入写入成功。
- 仅填食材用量或仅填步骤备注／计时的表单提交分别提示缺少食材名称或步骤内容，原快照不变。
- 模拟 Service Worker 激活时删除 v2、v3，保留 v4 和 `other-app` 缓存；未在真实 Cache Storage 中验证。

上述结果为此前报告的两项 P1 及两项 P2 风险提供了针对性模拟回归证据，但不能关闭真实浏览器回归。测试未覆盖真实文件选择／下载、刷新持久化、实际浏览器配额、完整 CRUD、移动布局或离线运行。
